NDM Ignore Lists

Keep downloads with your browser on the sites and file types below.

1 Ignored domains

One domain per line. NDM will not intercept anything from these sites.

Subdomains match automatically (e.g. "example.com" also matches "api.example.com").

2 Blocked file types

One extension per line (e.g. data). These are never intercepted, on any site.

Saved changes apply immediately — no need to reload the extension.
